# Maestro de marca L&C

- `lyc-logo-master.svg`: composición vertical principal.
- `lyc-logo-master-reverse.svg`: composición vertical para fondos oscuros o fotográficos.
- `lyc-logo-horizontal.svg`: composición horizontal para cabeceras.
- `lyc-mark-master.svg`: símbolo sin texto para favicon, redes y espacios pequeños.

## Especificación

- Dorado: `#B78A2D`.
- Azul tinta: `#0F1A3D`.
- Gris secundario: `#6B6F72`.
- Nombre: Times New Roman Bold.
- Descriptor: Arial Bold con espaciado amplio.
- Fondo: transparente.

Los SVG son editables y escalables. Antes de enviar a imprenta, convertir el texto a contornos desde Illustrator, Inkscape o Affinity Designer para eliminar dependencia tipográfica.
