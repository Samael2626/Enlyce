# DIAN: facturacion y nomina electronica para Enlyce

Consulta: 2026-10-09. Fuentes oficiales DIAN y su compilacion normativa. Esto cubre obligaciones DIAN; no define por si solo el alcance contable, laboral ni de facturacion que Enlyce deba ofrecer.

## Hallazgos accionables

- **No es obligatorio pagar un SaaS de Siigo ni otro proveedor para facturar.** DIAN admite tres vias: desarrollo propio/adquirido, servicio gratuito DIAN o proveedor tecnologico habilitado. El contribuyente puede operar directamente su software propio. Para software propio se registra el software en el sistema DIAN, se ejecuta el set de pruebas de habilitacion y solo se factura en produccion al superar pruebas y completar numeracion/asociacion de prefijos. [DIAN: ser facturador electronico](https://www.dian.gov.co/impuestos/factura-electronica/como-hacerlo/Paginas/ser-facturador-electronico.aspx); [Resolucion 000165/2023, arts. 28 y siguientes, compilada/modificada por Res. 000227/2025](https://normograma.dian.gov.co/dian/compilacion/docs/resolucion_dian_0165_2023.htm); [Concepto DIAN 13246/2025](https://normograma.dian.gov.co/dian/compilacion/docs/oficio_dian_13246_2025.htm).
- **Enlyce puede desarrollar para uso tributario propio.** DIAN distingue software propio (desarrollado directamente por el facturador) de software adquirido. La habilitacion valida que cumpla anexos tecnicos y reglas: XML, firma, transmision/validacion previa, entrega, notas credito/debito, recepcion y demas documentos que apliquen. La habilitacion del facturador para su propio NIT no convierte automaticamente a Enlyce en proveedor tecnologico autorizado para vender el servicio a terceros.
- **Cobrar por operar facturacion de otras empresas cambia la categoria.** Para actuar como proveedor tecnologico de factura se requiere habilitacion/autorizacion DIAN separada y condiciones empresariales, patrimoniales, de seguridad/calidad y pruebas. La Resolucion 000165 (texto compilado en 2025) incluye, entre otros, sociedad/sucursal constituida en Colombia, objeto social y RUT pertinentes, patrimonio contable minimo de 20.000 UVT con propiedad/planta/equipo minimo de 10.000 UVT, certificacion ISO 27001 (con plazo limitado para aportarla) y pruebas tecnicas. No construir el plan comercial suponiendo que basta con habilitar software propio.
- **Nomina electronica tambien admite solucion propia o gratuita.** La DIAN documenta tres modos para el emisor: solucion gratuita, software propio y proveedor tecnologico; habilitacion y pruebas se hacen por separado en la funcionalidad de nomina. El documento soporte se genera mensualmente y la regla general de transmision es dentro de los diez primeros dias del mes siguiente; incluir notas de ajuste cuando proceda. Deben cumplirse contenido y anexo tecnico, firma, CUNE, identificacion del software y conservacion/seguridad de datos de empleados. [DIAN: documento soporte nomina](https://www.dian.gov.co/impuestos/Paginas/Sistema-de-Factura-Electronica/Documento-Soporte-de-Pago-de-Nomina-Electronica.aspx); [Resolucion 000013/2021](https://normograma.dian.gov.co/dian/compilacion/docs/resolucion_dian_0013_2021.htm); [guia DIAN de modos nomina](https://www.dian.gov.co/impuestos/factura-electronica/Documents/Registro-y-Seleccion-del-Modo-de-Operacion-Nomina-Electronica.pdf).
- **Costos externos evitables:** licencia/suscripcion de un ERP o proveedor tecnologico, si Enlyce desarrolla y opera su software propio y asume mantenimiento. **La DIAN ofrece servicio gratuito** para factura, nomina, documento soporte y otros documentos; su certificado de firma puede solicitarse sin costo. Pero la solucion gratuita no ofrece integracion desde otra aplicacion (sus terminos excluyen conexiones/carga desde otros sistemas), asi que no equivale a una API gratuita embebible dentro de Enlyce. [DIAN: facturacion gratuita](https://www.dian.gov.co/impuestos/factura-electronica/facturacion-gratuita/paginas/default.aspx); [terminos DIAN de solucion gratuita](https://www.dian.gov.co/fizcalizacioncontrol/herramientaconsulta/FacturaElectronica/Facturaci%C3%B3n_Gratuita_DIAN/Documents/Documento%20de%20T%C3%A9rminos.pdf).
- **Costos/obligaciones que no desaparecen:** desarrollo, infraestructura y conectividad, soporte, monitoreo de rechazos/contingencias, seguridad y proteccion de datos personales; certificado de firma si se usa software propio (la gratuidad DIAN del certificado se anuncia para usuarios del facturador gratuito), cumplimiento y actualizacion de anexos tecnicos, habilitacion/pruebas, numeracion autorizada y archivo/entrega legal de documentos. Si se ofrece el servicio a terceros, se suman requisitos de proveedor tecnologico y sus costos de cumplimiento. La validacion previa de DIAN no reemplaza responsabilidades tributarias del emisor.

## Implicacion para el alcance Siigo

Tratar como dos decisiones distintas: (1) Enlyce como sistema interno de operacion contable/comercial y (2) Enlyce como emisor DIAN de documentos electronicos del propio NIT. Para llegar a una alternativa propia integrada y sin SaaS por transaccion, primero cerrar alcance funcional y habilitar factura electronica y, si hay empleados/obligacion, nomina en ambientes DIAN. No afirmar aun que esto sustituye Siigo completo: libros/contabilidad, impuestos, cartera, conciliacion, inventario y reportes requieren analisis funcional y normativo aparte. Antes de vender facturacion o nomina a clientes de Enlyce, hacer estudio separado de autorizacion como proveedor tecnologico.
