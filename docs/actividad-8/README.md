# Actividad 8 — Fundamentos del proceso de pruebas

Entregable individual de Samuel Andres Escobar Saldarriaga para Ingeniería de Software II.

## Archivos finales

- `Actividad_8_Fundamentos_Pruebas_Samuel_Escobar.docx`: documento editable de entrega.
- `render/Actividad_8_Fundamentos_Pruebas_Samuel_Escobar.pdf`: exportación usada para validar las 13 páginas.
- `evidencias/`: capturas reales incorporadas al informe.

## Regeneración

```powershell
cd docs/actividad-8/_scripts
npm install
node generar_actividad_8.js
```

`exportar_pdf.ps1` usa Microsoft Word para producir el PDF y comprobar la paginación real.

## Resultado documentado

El informe cubre instalación y herramientas, reporte consolidado, explicación de BOLA/IDOR, corrección propuesta, Next.js/TypeScript, `npm audit`, OWASP ZAP y pruebas de inyección SQL.
