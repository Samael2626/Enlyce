# Checkpoint — Enlyce — 2026-09-05

## Resumen

La web funcional de L&C incorporó un embudo público para propietarios. La nueva página permite solicitar acompañamiento para vender, arrendar o administrar un inmueble y registra la solicitud como lead en Enlyce.

## Cambios realizados

- Se creó `website/funcional/propietarios.html` con servicios, proceso y formulario.
- Se agregó navegación entre catálogo, fichas y propietarios.
- Se implementó la conversión segura del formulario al contrato actual de leads.
- Administración conserva su motivo en `Fuente` y usa temporalmente el pipeline `Arriendo`.
- Se agregó WhatsApp contextual, oculto mientras no exista número oficial.
- Se corrigió el comportamiento responsive detectado durante revisión visual.

## Estado actual

- Catálogo y página de propietarios responden en `http://localhost:4173/funcional/`.
- API saludable en `http://localhost:5019`.
- Una solicitud sintética de administración creó un lead en estado `Nuevo`.
- 14 pruebas JavaScript y verificación estructural de 29 archivos aprobadas.
