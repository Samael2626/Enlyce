# Checkpoint — Enlyce — 2026-09-04

## Resumen

La web pública funcional de L&C ya consume Enlyce.Api contra PostgreSQL. El catálogo local muestra 12 inmuebles sintéticos y permite abrir el detalle, filtrar y registrar contactos reales como leads.

## Cambios realizados

- Se agregó un sembrador de desarrollo idempotente con 12 publicaciones y 36 fotos sintéticas.
- El arranque opcional `DemoData:SeedPublicCatalog=true` aplica migraciones y carga el catálogo solo en desarrollo.
- Se agregó contacto por WhatsApp configurable sin inventar el número comercial.
- El formulario del detalle se verificó contra la API y creó un lead en estado `Nuevo`.
- PostgreSQL quedó aislado en el contenedor `enlyce-web-db`, puerto `55435`.
- La API quedó en `http://localhost:5019` y la web en `http://localhost:4173/funcional/`.

## Estado actual

- Catálogo: 12 resultados públicos y detalle funcional.
- Web: HTTP 200 y CORS válido desde `localhost:4173`.
- Pruebas: 224 .NET y 10 JavaScript aprobadas; verificador web aprobó 26 archivos.
- Servicios locales quedan ejecutándose para revisión.
