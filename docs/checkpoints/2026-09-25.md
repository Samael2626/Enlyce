# Checkpoint — Enlyce — 2026-09-25

## Resumen

La portada pública dejó de cerrar con un bloque geográfico y ahora conduce a dos acciones comerciales: contactar a un asesor o publicar una propiedad. La captación de propietarios usa el formulario real conectado a la API y toda la terminología visible del CRM cambió de “lead” a “oportunidad”.

## Cambios realizados

- Eliminado el rótulo “Medellín · Valle de Aburrá” del hero principal.
- Reemplazado “Zonas que conocemos de verdad” por un bloque editorial de conversión con accesos a contacto y propietarios.
- Integrado `ContactForm` directamente en `/propietarios`; las solicitudes conservan consentimiento Ley 1581 y llegan a `/api/leads`.
- Renombrados navegación, panel, alertas, pipeline, creación manual y estados visibles del CRM a “oportunidad”.
- Cambiado el correo automático de confirmación para hablar de una oportunidad registrada.
- Conservados nombres internos `Lead`, claves JSON y rutas `/api/leads` para evitar una migración incompatible sin valor funcional.
