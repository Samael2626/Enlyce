# Checkpoint — Enlyce — 2026-09-12

## Resumen
Se alineó la interfaz privada del CRM con la dirección editorial de la web pública de L&C. El trabajo se limitó a `frontend/`; no cambió la API ni el modelo de dominio.

## Cambios realizados
- Paleta crema, terracota y verde oscuro; tipografías Fraunces y DM Sans.
- Identidad real de L&C en login, navegación y favicon. Se usó el JPEG navy: el archivo PNG disponible no tiene transparencia real.
- Login, panel, navegación y pantallas de pipeline, leads, inmuebles y alertas ajustados al nuevo sistema visual.
- Imagen editorial de Medellín reutilizada en login y panel como placeholder temporal.
- Navegación al panel incorporada y textos visibles corregidos sin cambiar valores de API.

## Estado actual
`npm run build` y `npm run lint` pasan. Capturas reales verificadas en escritorio (1440 px) y móvil (390 px) para login y panel; sin desbordamiento horizontal en móvil. No se comprobó el flujo con datos reales de la API.

## Pendientes / próximos pasos
- Sustituir la imagen editorial temporal y el logo navy cuando L&C entregue activos definitivos, especialmente un PNG con transparencia auténtica.
- Revisar visualmente pantallas con datos reales y estados de edición.

## Decisiones y notas
Se conservaron hooks, rutas, formularios y contratos existentes. El cambio fue visual; no se habilitaron acciones que ya eran placeholders.
